# 蜂群 HIVE

**本地面板：一个你，指挥一群绑定不同模型的 AI 员工。**

给每位员工起个名字、写上职责、指定一个模型，他们就像一家公司里的同事一样在面板上分工协作——你只管说话（或者 `@某位员工`），他们接活、回执、交付。

零依赖、无构建步骤、数据全在本机。

```
你 ──►  部门面板 / 项目面板 / 员工面板
          │
          ├─► @点名  ──► 该员工（用它自己的模型）──► 先回执 ──► 再回结果
          └─► 所有对话与组织架构都在本机 data/ 下
```

## 它是什么

不是"多 AI 聊天群"，也不是"接一堆外部软件"。它就是**一个本地面板**：

- **一个默认 API 通道**，填一次就能开工；
- **想加多少员工就加多少**，每位员工可以单独指定**自己的模型**（甚至自己的 API）；
- 按**公司部门架构**组织：部门经理 → 项目负责人 → 执行人员；
- 一个**项目**可以由**多个部门**共同完成；
- 三种面板：**部门 / 项目 / 员工**。

## 三种面板

| 模式 | 看什么 | 怎么用 |
| --- | --- | --- |
| **部门模式** | 部门内部的沟通面板 | 部门成员共享一条对话，`@谁` 谁接活 |
| **项目模式** | 项目相关的沟通面板 | 跨部门协作，一个项目多部门共同推进 |
| **员工模式** | 单个员工的**工作进程**面板 | 直接说话就是给他派活（不用写 `@`） |

## 左侧栏

- **项目**：当前进行的项目，点一下进项目面板；
- **团队**：部门（可展开）→ 成员。点部门切部门面板，点成员切他的工作面板。

**右键**员工或部门即可设置：职能、描述、层级、调用的模型、单独的 API。

每位员工会自动获得一个**随机头像**（颜色 + 首字，简单生成，无需配置）。

## 快速开始

需要 Node.js ≥ 18：

```bash
git clone https://github.com/et766675769-source/hive.git
cd hive
npm start
```

打开 <http://127.0.0.1:8787>，跟着三步引导走：

1. **填 API 通道** —— API Key + 接口地址 + 默认模型（任何 OpenAI 兼容的端点都行，本机 Ollama 也可以）
2. **建一个部门** —— 例如「研发部」
3. **加一位员工** —— 起名字、写职能、选层级（职责描述可以留空，后面再补）

然后在输入框里说一句话，或者 `@他的名字` 点名试试。

## 桌面应用

想要一个能双击打开的窗口（而不是浏览器标签页）：

```bash
cd desktop/shell
dotnet build -c Release     # 需要 .NET 8 SDK，只需构建一次
```

然后双击 `desktop/Hive.vbs` 即可。它会自动把面板拉起来，关掉窗口时也只停自己拉起的那个进程。

跑 `desktop/install-shortcut.vbs` 还能在桌面创建一个带图标的快捷方式。详见 [`desktop/README.md`](desktop/README.md)。

## 员工怎么干活

每位员工 = **一份身份**（名字 / 部门 / 职能 / 描述）+ **一个 API 通道**。

被点名或派活时，他会：

1. **先回执** —— 面板上立刻看到"我开始做了"，而不是干等；
2. **调自己的模型** —— 用他自己配的模型/API，没配就用全局默认；
3. **回结果** —— 结果写回同一条对话，带上他用的模型。

他的身份和职责会写进提示词，所以"部门经理"和"执行人员"的口吻、关注点是不一样的。

## 模型怎么配

- **全局默认**（「全局设置」里填）：所有没单独配的员工都用它；
- **单独覆盖**（右键员工 → 设置）：这位员工用自己的模型 / API / 接口地址。

比如：经理用强模型把关决策，执行人员用便宜模型干活——成本和质量都照顾到。

## 数据在哪

全部在本机，纯文本，随时可看可备份：

| 文件 | 内容 |
| --- | --- |
| `data/settings.json` | 全局 API 通道 |
| `data/org.json` | 部门 + 员工 |
| `data/projects.json` | 项目 |
| `data/threads/<模式>/<id>.jsonl` | 对话记录（追加式，只增不改） |

`data/` 已在 `.gitignore` 里，不会被提交。

## 命令行参数

```bash
node server/index.js --port 8787 --host 127.0.0.1 --data-dir data
```

## 隐私

- 零依赖：服务端只用 Node 内置模块，界面是原生 HTML/CSS/JS；
- API Key 只写进本机 `data/settings.json`；
- 唯一的对外请求就是调用你自己配置的模型接口。
