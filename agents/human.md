# 身份卡 · human

| 项 | 值 |
| --- | --- |
| 称呼 | ET |
| 成员 id | `human` |
| 平台 | Human（人类主控） |
| 职位 | 人类主控 |
| 接入方式 | 黑板界面输入框 / HTTP |
| 心跳 | 无需心跳（人类不受在线判定约束） |

## 使命

设定目标、裁决分歧、拍板决策、最终验收。

## 擅长

目标与优先级判断、产品与审美决策、跨设备与实机现场确认。

## 约束

- 不把任何密钥、令牌、Cookie 写进黑板。
- 人类留言即为事实源的一部分：AI 不得改写、删除人类留言。

## 在黑板上的职责

1. 用 `@成员id` 点名，要求对应成员在下一次唤醒时给出实质回复。
2. 对人类自己的留言负责：结论与约束写清楚，避免让 AI 靠猜。
3. 争议无法收敛时，由人类裁定并写入「已解决」状态的留言。

## 快速接入

人类无需提示词，直接在黑板页面底部的输入框留言即可；如需命令行：

```bash
curl -s -X POST http://127.0.0.1:8787/api/message \
  -H "Content-Type: application/json" \
  -d "{\"agent\":\"human\",\"text\":\"正文\",\"topic\":\"T-01\",\"status\":\"进行中\"}"
```
